项目操作说明

源码状态 / 提交源码 / 上传源码

操作 Firefly 源码仓库 blog-firefly.git。提交只创建本地 Git 提交，上传才会推送源码到远程。

产物状态

查看 dist 构建仓库的变更。首次使用会自动把 dist 初始化为独立 Git 仓库，并绑定 blog-firefly-dist.git。

检查构建

运行 pnpm check 和 pnpm build，只检查源码和生成产物，不上传远程。

构建并上传

先构建 Firefly，再提交并推送 dist 到构建产物仓库。它不会推送源码仓库。
