Firefly 项目工作流

项目文件夹

连接 Firefly 根目录后，后台读取文章、动态及其图片资源。

远程仓库

git remote add 保存仓库地址；git push --set-upstream 完成首次推送并绑定分支。

源码仓库

依次使用 git status --short、git add -A、git commit、git push。源码仓库忽略 dist、依赖和备份。

检查与构建

pnpm check 只检查项目；pnpm build 全量生成静态站点和 Pagefind 索引。

dist 仓库

构建后在独立的 dist 仓库中查看、暂存、提交并推送构建产物。

内容备份

文章备份保存在后台 data/backups，不会进入 Firefly 内容目录或影响构建。

CONTENT ACTIONS

内容操作说明

点击内容行

点击标题所在的整行，进入独立 Markdown 编辑器。编辑器左侧是源文件，右侧是实时预览。

预览

打开只读预览页，检查 Markdown、图片、链接、表格和代码块的渲染结果。

文章发布 / 撤回

发布会将文章的 draft 改为 false；撤回会改回草稿。

动态发布 / 撤回

发布会把本地动态草稿写入 src/content/dynamic；撤回会将已发布动态移回后台草稿。正文和动态元数据会保留。

Git 与部署

文章和动态的发布状态操作不会自动执行 Git 提交、构建或部署。

删除

删除对应的源文件或本地草稿。该操作不可撤销，执行前会显示确认弹窗。
